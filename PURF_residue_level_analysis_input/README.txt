PURF residue-level analysis inputs

purf_training_sites.tsv
  Candidate IEP training-site labels.

purf_residue_features.tsv
  Genome-wide nonsynonymous residue-level predictor features used by PURF.

purf_annotated_ns_snps.vcf.gz
  Annotated nonsynonymous VCF used to map predicted residues to genomic SNPs.
  This VCF is not used to train the PURF model.
