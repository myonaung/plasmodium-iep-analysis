# CSP putative-serotype representation

This workflow extracts candidate IEP positions, calls CSP profiles from an
annotated VCF, estimates global and country-level representation, and produces
the associated geographic maps. An optional CSP-specific clustering step
corrects serotype ranking for oversampling of closely related infections.

## Inputs

- **Candidate-site summary:** antigen and gene identifiers, amino-acid
  positions and posterior candidate-IEP statistics.
- **Annotated multisample VCF:** SNP genotypes with SnpEff-compatible amino-acid
  annotations for the antigen region.
- **Sample metadata:** sample identifier and country for population-level
  summaries.
- **Optional cluster table:** `sample_id` and `cluster_id`, generated by the
  workflow in `clustering/`.

Only the required schema is described here; study-specific identifiers and
source data are not included.

## Example

```bash
bash run_csp_serotype_representation.sh \
  --annotated-summary data/site_annotations.csv \
  --vcf data/annotated_snps.vcf.gz \
  --metadata data/sample_metadata.tsv \
  --clusters results/csp_sample_clustering/csp_sample_clusters.tsv \
  --outdir results/csp_serotype_representation
```

Use `--sites ""` to derive positions using the configured candidate-IEP filters instead of the default CSP positions.

## Maps

```bash
Rscript scripts/plot_csp_reference_serotype_map.R \
  --calls results/csp_serotype_representation/CSP_serotype_representation/derived/aa_positions_calls.tsv \
  --metadata data/sample_metadata.tsv \
  --clusters results/csp_sample_clustering/csp_sample_clusters.tsv \
  --reference-serotype 'REFERENCE_PROFILE_FROM_CALLS_TABLE' \
  --out-prefix results/maps/csp_reference_serotype

Rscript scripts/plot_csp_cumulative_representation_maps.R \
  --coverage results/csp_serotype_representation/CSP_serotype_representation/country_bayesian/representation.country_cumulative_representation.tsv \
  --out-prefix results/maps/csp_cumulative_representation \
  --max-rank 4
```

The first map shows the country-level prevalence of a specified CSP profile.
The second shows cumulative representation as additional CSP putative
serotypes are included.

This clustering step is specific to CSP population-representation and mapping;
candidate-IEP inference and the general haplotype/serotype workflow do not
depend on it.
