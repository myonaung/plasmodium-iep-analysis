# Plasmodium immune-escape analysis

This repository provides the analysis code supporting a cross-species study of
candidate immune-escape polymorphisms in *Plasmodium falciparum* and
*Plasmodium vivax*.

## Start here

- [Installation](Installation.md)
- [Workflow overview](Workflows.md)
- [Input data](Input-data.md)
- [Outputs](Outputs.md)
- [Reproducibility](Reproducibility.md)
- [Frequently asked questions](FAQ.md)
- [Recommended GitHub settings](GitHub-repository-settings.md)

The workflows cover longitudinal candidate-IEP inference, haplotype reduction
to putative serotypes, CSP population representation, genome-wide PURF
prediction and supporting short- and long-read variant processing.

These are research workflows rather than clinical diagnostic software.
